ดาวน์โหลด Repository (แนะนำ) โหลด Add-on โดยตรง (v2.1.6)

วิธีติดตั้งใน Kodi (ใช้เวลา 2 นาที)

  1. เปิด Kodi ไปที่ Settings › System › Add-ons แล้วเปิด Unknown sources
  2. กลับไปที่ Settings › File manager › Add source
  3. กดช่อง <None> แล้วพิมพ์ลิงก์นี้: https://YOUR_GITHUB_USERNAME.github.io/ryustream/ ตั้งชื่อว่า ryustream
  4. ไปที่เมนู Add-ons › Install from zip file › ryustream แล้วเลือกไฟล์ repository.ryustream-1.0.0.zip
  5. เข้าเมนู Install from repository › RyuStream Repository › Video add-ons แล้วกดติดตั้ง RyuStream
  6. เปิด RyuStream กดปุ่ม บัญชี & ตั้งค่า เพื่อเชื่อมต่อ AllDebrid ด้วยรหัส PIN 4 หลัก
