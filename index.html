How to Install in Kodi (2 Minutes)

  1. Open Kodi, go to Settings › System › Add-ons and enable Unknown sources.
  2. Go back to Settings › File manager › Add source.
  3. Click <None>, type: https://witty11444.github.io/ryustream/ and name it ryustream.
  4. Go to Add-ons › Install from zip file › ryustream and select repository.ryustream-1.1.5.zip.
  5. Go to Install from repository › RyuStream Repository › Video add-ons and install RyuStream.
  6. Open RyuStream, click Debrid Cloud (Authorize) and scan the QR Code with your phone.
